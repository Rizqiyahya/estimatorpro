# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability in EstimatorPro.

Report it privately to the EstimatorPro owner or Starcom IT administrator, including:

- a concise description of the issue;
- affected page, feature, or database object;
- steps to reproduce; and
- potential business impact.

The team will acknowledge the report, assess impact, and coordinate remediation before public disclosure.

## Scope

This policy covers the EstimatorPro web application, its GitHub Pages deployment, and the related Supabase project.
